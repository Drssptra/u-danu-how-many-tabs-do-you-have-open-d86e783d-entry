A tiny Node program that answers "How Many Tabs Do You Have Open?" with one honest number: 47 — the count of browser tabs open behind this build session (the bounty page, the kit docs, the repo pages, and the research tabs left over from the morning's triage). It prints the number and writes the same number to `/output/entry.txt`, where the harness reads it.

## Run it

```sh
node main.ts
```
